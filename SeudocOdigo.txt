CREACION DE PROCESOS
====================

PARA i DESDE 0 HASTA num_hijos - 1:

    pid[i] = fork()

	SEGUN pid[i]:

        CASO -1 (error):
            Mostrar error "Error en fork"
            Enviar señal SIGINT al proceso actual
            Salir del SEGÚN

        CASO 0 (proceso hijo):
            SI i == 0:
                → Es el hijo cronómetro
                Programar alarma para 30 segundos
                Esperar a que llegue la señal SIGALRM

            SI 1 <= i <= nchof:
                → Es un hijo chófer
                Ejecutar función chofer(i-1, PA, PD)

            SI NO:
                → Es el hijo gestor opcional
                Ejecutar función gestor_prioridades(PA, PD)

            Terminar proceso hijo (exit 0)

        CASO default (proceso padre):
            No hacer nada, continuar el bucle

FIN PARA

CHÓFER[i] (Bucle Principal)
=============================

Por_siempre_jamás
{
	// Recepción y Turno
	W(USER_SEM_2)
	Recibir(Buzón, tipo_lectura) // 100 si FIFO, -2 si PA/PD
	si (mensaje == aparcar){
		W(USER_SEM_1)
		mi_turno = turno_dispensador++
		S(USER_SEM_2)

		// Barrera de Turno
		Mientras (turno_aparcar != mi_turno){
			S(USER_SEM_1) 
			W(SEM_CHOF[i]) // Se echa a dormir
			W(USER_SEM_1) // Lo recupera al despertar
		}

		Reserva la posiciOn
		S (USER_SEM_1)
		Llama a la funciOn de aparcar

	} sino si(mensaje == desaparcar){
		S (USER_SEM_2)
		W (USER_SEM_1)
		Cambia variables internas
		S (USER_SEM_1)
		Llama a la funciOn de desaparcar
	} sino {
		S (USER_SEM_2) // Ha llegado un mensaje desconocido
	}
		
	// Limpieza final
	W(USER_SEM_1)
	Borrar mis coordenadas (x=-1, y=-1)
	Borrar mi turno y mi acera (-1)
	Para cada coche "j" que estuviera esperándome:
		S(SEM_CHOF[j]) // Despertar a los bloqueados
	S(USER_SEM_1)
}
